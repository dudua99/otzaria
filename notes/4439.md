# Issue #4439 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: none against; dudua99 18.11 confirmed gap in code and proposed the fix.

## Requested behavior
Ctrl+Enter submits the app report ("דיווח מהתוכנה") like it already does in the book error-report dialog and the personal-note editor.
- Ctrl+Enter (Cmd+Enter on macOS) inside AppReportDialog triggers exactly the primary action of the `app-report-send` button.
- Respects the same enable rules as the button: no-op when `editing == null`, `busy` (isSending), or `loadFailed` (button hidden).
- In `finalizing` state the button reads "סיים שמירה מקומית" — the shortcut does the same thing the button does.
- Offline mode: shortcut queues (same as the button: `AppReportSubmitted(queueOnly: _offline)`).
- Tooltip on the send button shows the shortcut (like error_report_dialog).
- Plain Enter keeps DD-08 behaviour (Enter by focus; newline in multiline description).

## Where in the code
- lib/app_report/view/app_report_dialog.dart: `_buildActions` (~L410-460) — send button `ValueKey('app-report-send')`, onPressed `_bloc.add(AppReportSubmitted(queueOnly: _offline))`; `build` (~L107) returns `AppDialogFrame(size: AppDialogSize.large)`.
- Pattern to copy: lib/text_book/view/error_report_dialog.dart L1416 `const _sendShortcut = 'ctrl+enter'`, L1664-1672 `CallbackShortcuts(bindings: {for (a in ShortcutHelper.activatorsFromShortcut(_sendShortcut)) a: ...})`, L1976 `tooltip: ShortcutHelper.formatShortcutForDisplay(_sendShortcut)`.
- Also uses it: lib/personal_notes/widgets/personal_note_editor.dart.

## Implementation sketch
- Extract the send-button predicate into one getter/method (`_canSend(state)` + `_send()`), used by both the button and the shortcut, so they never drift.
- Wrap the dialog body (not only the actions) with `CallbackShortcuts` so the binding fires while focus is in any field (CallbackShortcuts must be an ancestor of the focused field).
- Do not hard-code control: `ShortcutHelper.activatorsFromShortcut` already maps to meta on macOS — verify.
- Optional (scope check with reviewer): other send dialogs without the shortcut — grep `AppReportSubmitted`/send buttons in lib/settings/dialogs/reports_management_dialog.dart; keep PR to the app report dialog unless trivial.
- No new user strings (tooltip text is the formatted shortcut).
