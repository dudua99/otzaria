## Requested behavior / DEFAULT
DEFAULT (reading-order aware, RTL book): when the current page is wider than the viewport (horizontal overflow), Left/Right first pan horizontally by a step (same step as arrow Up/Down vertical scroll); only when the view is already at that horizontal edge does the key turn the page (next = Left at the left edge, previous = Right at the right edge), like PDF readers. When the page fits the width — unchanged (immediate page turn). PageUp/PageDown, held-key continuous turning, book-view (spread) mode and the configurable shortcuts are unchanged. No new setting.
Acceptance:
- Widget/unit test (pure helper preferred): given viewport/content horizontal metrics, `ArrowLeft` → pan when `extentLeft > 0`, page turn when at the edge; fits-width → page turn (fails on dev: always page turn).
- Held Left/Right while zoomed pans continuously and does not queue page turns until the edge.
- Existing PDF key tests (grep test/pdf_book for `arrowLeft` / `_isNextPageKey` / PageDown) stay green.
