# Issue #2348 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: palmoni5 11.10 "CTRL+חץ מעביר, לא?" (page turn exists); Y-PLONI 03.11 diagnosis: ↑/↓ not wired to the reading scroll; "להוסיף גלילת ↑/↓ באזור הקריאה".

## Requested behavior
In תיקון קוראים (tikkun korim) the keyboard should scroll the reading column.
Acceptance:
- ↑ / ↓ scroll the reading list by a line-step (smooth, like the text reader), PageUp/PageDown by ~a viewport (without Ctrl; Ctrl+PageUp/Down stays page-turn).
- Home/End optional (top/bottom of current column page).
- Keys are ignored while a text field is being edited (`_isEditing()`), while settings/bookmarks panel has focus, and while zoom modifier lock is on.
- Ctrl+←/→ page turn unchanged. Focus is not stolen from the arrow buttons when the user tabbed to them (only act when the screen-level Focus or the list has focus).
- Out of scope for this PR: "continuous scroll with page-break markers" (2nd request) — the "עמוד אחד ארוך" mode already exists (tikkun_processor.dart ~L488-505); mention it to the reporter.

## Where in the code
- lib/tools/tikkun_korim/view/tikkun_korim_screen.dart `_keyBindings` (~L340-405): CallbackShortcuts map with Ctrl+arrows, zoom, Esc; screen Focus `_keyboardFocusNode` autofocus (~L325-333); `_scrollController = ItemScrollController()` (~L89).
- lib/tools/tikkun_korim/view/widgets/reader_page.dart `_buildList` (~L268): `ScrollablePositionedList.builder(itemScrollController: widget.scrollController, itemPositionsListener: ...)`; `physics` Never when `_zoomModifier`.
- Reuse: `ScrollOffsetController` from scrollable_positioned_list, as in lib/text_book/view/reading_viewport/line_scroll_controller.dart:89 (`offsetController.animateScroll(offset:, duration:)`) and page_shape_screen.dart:1959.

## Implementation sketch
- Add `final ScrollOffsetController _offsetController` in the screen, pass to ReaderPage → `scrollOffsetController:` of the list.
- In `_keyBindings` register plain arrowUp/arrowDown (step = one rendered line height from `TikkunRenderMetrics`, or a fixed `AppTokens`-free px constant derived from metrics.em) and pageUp/pageDown (viewport height * 0.9 via LayoutBuilder value kept in state). Use `AppMotion` duration (respect reduced motion, DD-21).
- Guard with `_isEditing()` like turnPage.
