# Issue #4937 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: none (no maintainer comment).

## Requested behavior
Add a 4th choice to "העתקת הכותרת" (settings → text → copy): "כותרת בלבד" — the copied citation contains only the heading path (e.g. "שבת ד, ג") without the book name, so the user can write "וכן כתב הרשב"א (שבת ד:)".
- New option appears in the segmented tile next to ללא / שם הספר / שם וכותרת.
- With it selected, every copy path that uses headers adds only `currentPath` in the chosen header format (brackets/before/after/separate line — the existing `copyHeaderFormat` dropdown stays visible).
- If the current path is empty (book without TOC position) fall back to the book name (never paste an empty "()").
- Existing users keep their current value; default unchanged.

## Where in the code
- lib/utils/text/copy_utils.dart `formatTextWithHeaders` (~L204-255): branches on `copyWithHeaders` 'none' / 'book_name' / 'book_and_path'. Add a branch here — single point for all callers.
- Callers (no change needed if they pass currentPath): lib/text_book/view/selection/selected_text_copy.dart:188/196, lib/text_book/utils/reader_paragraph_copy.dart:32/39, lib/utils/ui/context_menu_utils.dart:458/466, lib/search/utils/search_result_copy.dart:23 (uses `CopyUtils.referencePath`), lib/semantic_search/view/semantic_search_results_screen.dart:466.
- Verify `extractCurrentPath` (copy_utils.dart ~L120-175) does not already prepend the book name for some books (TOC root = book title); if it does, strip it for the new mode.
- Settings UI: lib/settings/tabs/text_settings_tab.dart `_buildCopySection` (~L440): `SettingsSegmentedTile<String>` options. Persisted key `copyWithHeaders` via SettingsRepository (string, no migration).
