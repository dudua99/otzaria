# Issue #5989 — copying from a personal note with Ctrl+C does not work (sweep 26.11 part 3)
Type: bug. Checked on dev 4fe1973a4.

## Report
"העתקה מהערה בקוטרול ב לא עובדת, בכל הוריאציות, ריחוף והערת צד". "קונטרול ב" = Ctrl+C on a Hebrew keyboard layout (ב is on the C key).
dudua99 (on GitHub) verified one place and asked which of the three places fails; no answer yet.

## Evidence (file:line on dev)
- lib/personal_notes/widgets/commentary_notes_section.dart:81-110 — the "הערות על המפרשים המוצגים" area shows the title and excerpt as `Text` inside `ListTile` with no `SelectionArea`/`AppSelectionArea`: the text cannot be selected or copied at all. Unchanged since 4cca990b9 (2026-10-04, issue #1637) — the root cause for this place.
- The expanded note and the hover popup use `PersonalNoteContentView` (selection fixes #1595/#1598, #3260/#4226).

## Fix
1. Wrap the note content in commentary_notes_section.dart in the app's selection widget (`AppSelectionArea`, as in PersonalNoteContentView), keeping the ListTile tap working (tap opens the note; drag selects).
2. While at it, verify with a widget test that Ctrl+C copies a selection in the hover popup and in the side note (PersonalNoteContentView), including a key event whose logical key is keyC but whose character is 'ב' (Hebrew layout). If those tests pass on dev, keep them as regression tests and scope the PR to the section ("Refs #5989" if the other two variants could not be reproduced; "Fixes" only if all three are covered).
