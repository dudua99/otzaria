# 6062 — Android: opening "כלים" (tools panel) pops up the keyboard

## Summary
Forum request: on Android, tapping "כלים" opens the soft keyboard because the panel focuses its search field.

## Evidence
- `lib/tools/view/tools_launcher_panel.dart:222-230` initState: post-frame `_searchFocusNode.requestFocus()` on every open; also line 959 `onMenuClosed: () => _searchFocusNode.requestFocus()`.
- Introduced in 24ddea5be (palmoni5, 01.09, "פאנל הכלים: פוקוס לשורת החיפוש בכל פתיחה (issue #1039)") — a desktop convenience, no platform check.
- Precedent for exactly this: c222d5ac7 ("במובייל המקלדת אינה נפתחת מעצמה...") with `shouldAutofocusLibrarySearch(TargetPlatform)` in `lib/library/view/library_browser.dart:137` (android/iOS -> false).

## Fix idea (minimal)
Gate both requestFocus calls on the same platform rule (reuse/extract `shouldAutofocusLibrarySearch` logic — don't create a third copy; there is already a duplicate in main_window_screen.dart:284). Desktop behavior (#1039) unchanged.

## Test idea
Widget test with `debugDefaultTargetPlatformOverride = TargetPlatform.android`: open the panel, pump -> search field has no focus (dev: focused). Windows override -> focused (keeps #1039).

## Pitfalls
- Reset `debugDefaultTargetPlatformOverride` in tearDown.
- Keyboard-only users on Android tablets: acceptable, same as library search.
