## Requested behavior
In the commentary panel, a Be'er HaGolah item whose printed marker is ג must not be headed with a conflicting ordinal ד (e.g. "ג באר הגולה …, תרסד, ד").
DEFAULT: when an anchor marker is shown (`markerText != null`) and the display reference's LAST segment is a Hebrew ordinal that differs from the marker letter, drop that last segment from the header (keep book + siman). When equal or no marker → unchanged.
Acceptance (default):
- תרס״ד: `[ג]` item header shows "ג" + "באר הגולה … תרסד" without the trailing "ד"; the `[•]` item unchanged; items before the circle (where marker == ordinal) unchanged.
- Link targets, navigation on click, copy of the commentary (`onLinkTitleRendered` → copy restore) use the same header string (no mismatch between shown and copied).
- PDF commentary panel and links list show the same rule where they compose marker + reference.
