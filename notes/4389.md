# Issue #4389 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: none. NEEDS_DECISION (control placement); default below.

## Requested behavior
Hiding "ציוני המפרשים" (commentary markers) doesn't hide footnote markers printed in the body text (e.g. numbers "(9)" / `<sup>(א)</sup>` in ביאור חברותא, שמירת שבת כהלכתה); they also get copied. The reporter suggests a SEPARATE control (some users want commentary markers hidden but footnotes shown).
Question: separate visibility for footnote markers, or fold them into "ציוני המפרשים"?
DEFAULT: separate field `footnoteMarkers` (MarkVisibility show/hide) in the same text-display patch system as `anchorMarkers`, default show (no change for existing users), applied to display, copy and export.
Acceptance (default):
- Settings → text display → "התאמות נוספות"/advanced: new row "ציוני הערות שוליים" הצג/הסתר, per scope like other patches (book/category/global).
- When hidden: markers recognised by numbered_note_markers.dart (numbers `(\d{1,4})` wrapped as anchors, and `<sup>(letter)</sup>`) are not rendered and not copied; hovering behaviour irrelevant. Plain-text "(9)" that is NOT recognised as a footnote marker stays (no regex guessing beyond the existing recogniser).
- Dynamic shortcuts can toggle it (DynamicShortcut change field) for parity with anchorMarkers.
- Search/index unaffected.
