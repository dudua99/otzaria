# Issue #5608 — feature notes (verify everything)
Type: FEATURE/design (milestone 0.9.99; labelled bug). Assignee: Nathaniel-260 (maintainer; palmoni5 assigned him 19.11). Maintainer stance: none beyond the assignment. NEEDS_DECISION: the issue is assigned to a design maintainer — implement only if the owner/Nathaniel agree; default below.

## Requested behavior
Zmanim cards (calendar → "זמני היום"): the time digits should be larger and truly centred; the bell (alert) icon should appear only for those who want it.
Default spec:
- Time value uses a larger text ROLE (e.g. `textTheme.titleMedium` bold) instead of `bodySmall` bold; no literal fontSize (AGENTS UI rules).
- Time is centred on the card's full width: the bell no longer takes a slot in the Row; it is laid out as an overlay at the end edge (PositionedDirectional / Stack) so it does not shift the time.
- Bell visibility: always visible when an alert is set (filled icon + minutes label); otherwise shown only on hover or keyboard focus of the card (desktop pointer), and always shown (subdued) on touch devices — decide by actual pointer like DD-31b ("רק" button by real pointer). No new setting (avoid settings growth per #1478 discussion).
- Composite cards (two values) keep their layout; apply the same overlay rule to their alert control.

## Where in the code
- lib/tools/calendar/widgets/calendar_times_panel.dart: plain time `Text(_display(timeData.time), textAlign: center, style: bodySmall bold)` ~L911-918; `_AlertControl` Row slot ~L920-936; `_AlertControl` widget ~L979-1027 (BarButton.icon compact + minutes label with Opacity); composite row `_buildAlertedCompositeRow` ~L873.
- Pointer-kind precedent: search scope "רק" button (DD-31b) — find helper used there for hover-vs-touch.

## Implementation sketch
- Wrap each card body in a `Stack`; time `Center`; `_AlertControl` in `PositionedDirectional(end: 0, bottom: 0)`; reserve no width.
- Hover state via `MouseRegion` + `FocusableActionDetector` on the card; `AnimatedOpacity` with `AppMotion` (DD-21 reduced motion → no animation).
- Keep tooltip on the icon button (UI rule) and Semantics label for screen readers even when visually hidden (do not remove from tree; use opacity + `ExcludeSemantics(false)`).
