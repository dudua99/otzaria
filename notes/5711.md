## Requested behavior
Every character typed in the in-book search field (text book, left pane "חיפוש") stays in the field, at any typing speed; the search runs on the final text.
Acceptance:
- Type "אב", pause past the debounce (250ms), type "ג" while the bloc echo of "אב" is still on its way → field = "אבג", search runs for "אבג" (fails on dev: field reset to "אב", caret at end, "ג" lost).
- Several pauses/keystrokes in a row (a b <debounce> c <echo> d <debounce> e) → field = full text.
- Real external changes still sync into the field: top search bar / advanced search dialog / opening a global result (existing test 'שינוי חיצוני אמיתי של השאילתה עדיין מסונכרן לשדה' stays green) and #1430 echo test stays green.
