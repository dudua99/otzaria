# Issue #3722 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: Y-PLONI 03.11: "להציג את הסכום אחרי גילוי העדכון ולפני תחילת ההורדה, עם אפשרות לדחות אותה. להבהיר שזה גודל עדכון המסד; קבצים נלווים ... אינם נכללים" + tests for single delta, delta chain, full download, and that deferring does not start a download.

## Requested behavior
Show the estimated download size of a regular (non-heavy) library delta update before it downloads, so users on metered/USB-stick setups can defer it (like attached DBs already show).
Acceptance:
- After a check finds a delta (`LibraryUpdatePlanKind.delta`, not heavy), the user sees "עדכון ספרייה זמין (גודל הורדה משוער: X MB)" with "עדכן" and "לא עכשיו" BEFORE any byte is downloaded.
- "לא עכשיו" ends the run without downloading (state completed/idle with hasUpdate false), and the next automatic check may offer it again.
- Text clarifies the size is the database update only; companion assets updated separately are not included (or included when their size is known — optional).
- Full download and heavy-delta paths unchanged (they already show size: library_update_bloc.dart ~L294-312).
- DEFAULT FOR AUTOMATIC CHECKS (decide in PR, flag to reviewer): to avoid turning silent auto-updates into a prompt for everyone, prompt only when `_userInitiated` OR size ≥ a threshold (e.g. 50 MB); otherwise proceed and show the size in the progress status line. If reviewers prefer "always ask", it's a one-line change.

## Where in the code
- lib/library_update/bloc/library_update_bloc.dart `_onCheck` (~L236-330): `case LibraryUpdatePlanKind.delta:` → `_runDelta(plan, emit, opId)`; `_formatSize`, `plan.totalDownloadSize` (sum of compressed files incl. chained deltas, computed in otzaria_library_updater `library_update_plan.dart` L225-236).
- Existing confirmation pattern: `LibraryUpdateStatus.needsFullConfirmation` (library_update_state.dart L23) and its UI: main_window_screen.dart ~L1292 and ~L3194, library_browser.dart L113, library_update_work_status.dart L37.
- Messages: `LibraryMessages` in lib/core/messages/ (UiSnack catalog) — add `deltaSizeConfirm(size)`.

## Implementation sketch
- New status `needsDeltaConfirmation` (or reuse needsFullConfirmation with a `plan.kind` check — prefer a new enum value for clarity) carrying `plan`.
- Confirm event → `_runDelta(plan,…)`; decline event → emit idle/completed without downloading.
- Wire the same UI surfaces that handle needsFullConfirmation.
