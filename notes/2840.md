# Issue #2840 — bug notes (verify everything)
Type: BUG (milestone 0.9.99). Assignee: none. Maintainer stance: Y-PLONI 03.11 (dev@5fecad2) diagnosis + direction: the commentary panel sends `OpenOrFocusTab` WITHOUT `navigateToPositionIfReused`, while find-ref (איתור) sends `true`; so the panel match also requires an equal location heading and can open a duplicate tab when the commentary is already open elsewhere. "להחיל את מדיניות האיתור גם בפתיחה רגילה/״פתח ועבור״ מהחלונית, כולל גלילה לקטע המבוקש. לשמר יצירת עותק בפעולה המפורשת ״פתח בכרטיסייה חדשה״". No open PR.
Constraint: no visual change; keep the explicit "open in new tab" action creating a copy.

## Requested behavior
Opening a commentary from the side commentary panel when that commentary book is already open in a tab must focus the existing tab and navigate it to the requested passage (as find-ref does), not open a new tab.
Acceptance:
- Commentary book X already open (any heading/line) in tab T; open X from the panel of book Y at another passage → no new tab; T becomes active and scrolls/highlights the requested line.
- Same for X open inside a split (combined) tab: the matching pane becomes active and navigates.
- Explicit "פתח בכרטיסייה חדשה" (tabbed_commentary_panel.dart ~L186, `openInNewTabTooltip`) still creates a new tab.
- X not open → unchanged (new adjacent tab).

## Where in the code (upstream/dev)
- lib/tabs/reading_screen.dart L524-529 (`TextBookViewerBloc.openBookCallback` → `OpenOrFocusTab(tab, insertAdjacent: true)`) and L548-553 (`CommentatorsTabScreen.openBookCallback`, same). Neither passes `navigateToPositionIfReused`.
- lib/tabs/bloc/tabs_bloc.dart `_onOpenOrFocusTab` L580-640: `ignoreLocation = matchBookOnly || navigateToPositionIfReused` (L595-596); without it `_resolveTabLocationTitle` + `_findMatchingTopLevelTabIndex(... ignoreLocation:false)` require the same heading → no match → new tab. Navigation of a reused tab only when `navigateToPositionIfReused` (L631-635).
- Find-ref reference behavior: lib/find_ref/view/find_ref_dialog.dart L699, L784; text_book_screen.dart L2228/L2293/L2329/L3246 already pass `true`.
- Callers that flow into this callback: commentary_list_items.dart L214/L545/L769, widgets/commentary/commentary_content.dart L133/L181, combined_book_screen.dart L590/L3408, page_shape/simple_text_viewer.dart (links). Check that every one of them is a "go to" action (not an explicit "new tab").

Run `git log -L524,555:lib/tabs/reading_screen.dart upstream/dev` and `git log -S navigateToPositionIfReused upstream/dev` to find when find-ref got the flag and the panel callback did not (regression-first: name the commit in BODY).
