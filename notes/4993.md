## Requested behavior
"When I open a commentator on the Mishna and click 'more commentators' (עוד פרשנים) there is a list of commentators but no option to open all of them, as there is from the Mishna itself."
Report context (app report r4993): current tab "תוספות יום טוב על משנה מכות", TextBookTab, view "split", commentators: 0 — i.e. the reader opened a COMMENTARY book as the main text.
Acceptance (to confirm after reproducing):
- In the commentator-selection list shown for a book that is itself a commentary, there is the same "הצג את כל המפרשים" row (select-all of visible) that the base text gets.
- Selecting it opens all listed commentaries in the commentary pane, like on the base text.
