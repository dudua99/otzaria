## Requested behavior / DEFAULT
DEFAULT: in Settings → קיצורי מקשים, a read-only card "קיצורים קבועים" (shortcuts that cannot be changed), each row = label + key chip, no edit/reset controls:
- Ctrl+Tab — הכרטיסייה הבאה; Ctrl+Shift+Tab — הכרטיסייה הקודמת
- Ctrl+1 … Ctrl+8 — מעבר לכרטיסייה לפי מיקומה; Ctrl+9 — הכרטיסייה האחרונה
- F11 — מסך מלא; Esc — יציאה ממסך מלא / סגירת השכבה העליונה
Only list keys that are really hard-coded on dev (verify each against keyboard_shortcuts.dart; drop any that turns out to be configurable). Ctrl+Shift+A (tab search) is already a configurable tile in the "תצוגת ספר" card — do not duplicate; optionally mention it in the card subtitle.
