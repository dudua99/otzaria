Type: BUG (from-app, Windows 0.9.98.3, report 1ac0c410; screenshot exists — do not open). Assignee: none. Maintainer stance: none (no comments). No open PR. Reporter: opening a search result in a long section (e.g. תורת הבית) scrolls inside the section, but to the FIRST red-highlighted spot, which is a partial quote, not the real match further on. Query: `בסמוך בוסת הדילוג אמרינן דשמואל`, options: prefixes + full spelling (כתיב מלא), distance 0 ("בלי רווח בין המילים").
Constraint: no change to which lines are results or to highlighting colors; only the scroll target inside the line.

## Requested behavior
Opening a global search result (and moving between in-book results) scrolls to the occurrence that is a COMPLETE match of the query (all words, in order, within the distance), not to the first highlighted fragment.
Acceptance:
- Unit test: `matchFractionInLine(line, query, searchOptions:{prefix+full spelling}, searchDistance:0)` where the line has, first, a partial quote (2-3 of the words, highlighted) and later the full phrase → fraction points at the full phrase (fails on dev if the hypothesis below holds).
- Line where only partial matches exist (non-standard match policy / fuzzy per-word path) → keeps today's behavior (first highlight).
- Existing test/text_book/utils/match_fraction_engine_highlight_test.dart (#1642) and section_search_utils_test.dart stay green.

## Root cause — hypotheses to prove FIRST (reproduce with a test string, no library needed)
(a) With prefix + full-spelling options the highlight pattern accepts a fragment that the engine did not count as the match (e.g. distance/full-spelling regex lets 2-3 words match as a "phrase", or `partialWordMatch` from `literalPartialWordMatch` relaxes boundaries) → first range is the fragment.
(b) The search runs with a non-standard match policy (paragraph/heading scope or "at least N words") → per-word highlighting, so the first single word wins.
(c) The in-book result selected first is a different occurrence (engine `matchOffset` null) → same path.

If none of (a)-(c) reproduces → VERDICT NOT READY with the evidence and ask (via BODY) for the book/section.
