## Requested behavior
Users with several workspaces (שולחנות עבודה) can't tell which one is active. Show it — on hover of the switch-workspace icon, or as text in the title bar.
Acceptance:
- The title-bar workspace button tooltip reads "החלף שולחן עבודה ({shortcut}) · נוכחי: <שם>" (settingsText with args) when an active workspace exists.
- Optionally (desktop, wide window only): the active workspace name is not added as permanent title text in this PR — keep it to the tooltip + the switcher dialog marking the active item (WorkspaceSwitcherDialog already marks the active item: workspace_switcher_dialog.dart:124 `isActive`).
- When no WorkspaceBloc is in the tree (tests, secondary windows) or no active id → tooltip unchanged. MUST NOT throw (this is what broke #5528).
