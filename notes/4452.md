# Issue #4452 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: palmoni5 07.11: "רעיון מעניין: קיצור דינמי/אופנציונלי להגיע למסך מסויים בהגדרות" (a dynamic/optional shortcut to reach a specific settings screen).

## Requested behavior
A keyboard shortcut, available everywhere, that opens the keyboard-shortcuts list (settings → קיצורי מקשים) so users can memorise/check shortcuts quickly.
Acceptance:
- New configurable shortcut `key-shortcut-open-shortcuts-list` (ShortcutValidator constant), label "רשימת קיצורי המקשים", default `ctrl+slash` IF free (verify conflicts in defaultShortcuts and plugin_host_shortcuts reserved list); if the team prefers "optional" (palmoni5), default '' (unassigned) like `openAppReportKey` — DEFAULT CHOICE: ctrl+/ (discoverable; standard in many apps), state it in the PR so maintainers can flip to ''.
- Pressing it opens Settings on the Shortcuts tab (same route as `otzaria://…settings/shortcuts` → `SettingsTab.shortcuts`, external_uri_router.dart:335) from any screen/window; if Settings is already open, switches to that tab.
- Listed and editable in the shortcuts settings tab; works on macOS menu if applicable (mac_menu_bar.dart pattern).
- (palmoni5's generalisation — "shortcut to a specific settings screen" — not required; mention as follow-up.)
