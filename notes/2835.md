## Requested behavior
In "מפרשים מתחת" mode, a single click on a passage opens/closes the commentaries below it; accidental clicks or attempts to select text toggle it. Reporter asks for double-click instead.
Question: (a) keep single click; (b) Y-PLONI's proposal: a small expand chevron beside each paragraph opens/closes commentaries, plus a (default ON) option "פתיחה בלחיצה על הטקסט" that keeps today's behaviour; (c) double-click (conflicts with word selection — rejected by Y-PLONI).
DEFAULT: (b) with the click-on-text option default ON (no behaviour change for existing users), chevron always available.
Acceptance (b):
- Each main-text paragraph in commentaries-below mode shows a chevron at the paragraph's end edge (DD-27 direction rules) when it has commentaries; activating it toggles that paragraph's commentaries; keyboard focusable, tooltip "הצג/הסתר מפרשים".
- Setting off → clicking text never toggles; selection/drag unaffected.
- Continuous mode respected.
