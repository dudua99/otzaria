## Requested behavior
In continuous reading (קריאה רציפה), the selected source line/verse is marked only by a side bar; when several verses share one visual paragraph the user can't tell which verse is selected (the one the commentaries follow).
Acceptance:
- ONLY in `ReadingLayout.continuous`: the selected verse's text range gets a subtle translucent background (exact rects of that source line inside the merged paragraph, not the whole paragraph).
- Priority: permanent mark > highlighted (search/link) > selected-subtle > none. Multi-selection: each selected line gets the tint.
- Non-continuous layouts: unchanged (side marker only).
- Works in light/dark/"לבן"; colour from a theme role (e.g. `AppSurfaces` selected-row role at low alpha; if a new role is needed → AppSurfaceColors + test/theme contrast, per AGENTS; prefer existing `selectedRow`-type token).
- Commentary pane behaviour unchanged (isRelated stays side-marker only, #4664 / commit 43b64bd4c).

## Implementation sketch
- Add `ReaderLineBackground.selectedSubtle` (or a separate flag) produced only when layout is continuous and line ∈ selectedIndices and no stronger background.
- In the continuous render path paint rect-level tint using the existing rect map (not a full-width container).
