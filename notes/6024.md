# 6024 — book export dialog: "choose export format" hint sits above the holy-names section

## Summary
In the whole-book export dialog the text "בחר פורמט לייצוא" is the first line, then the section "שמות הקודש בקובץ הזה", and only then the format buttons (טקסט / Word). The hint is separated from the buttons it describes; the reporter expects: settings (holy names) first, then the format choice next to the buttons.

## Evidence
- `lib/text_book/view/text_book_export_dialog.dart:36-56`: title 'בחירת סוג קובץ'; first child `Text('בחר פורמט לייצוא')` (line 49), then `_SectionLabel('שמות הקודש בקובץ הזה')` (line 55) + AppCard; format buttons are `choices:` of `showChoiceDialog`, rendered below customContent.
- Layout came from 671616404 / e8b6e677f (design system unification). Still present on dev.

## Fix idea (minimal)
Move the "בחר פורמט לייצוא" hint below the holy-names card (as the last child of the column, styled as `_SectionLabel` like the other section), so the order is: holy names -> format -> buttons. Optionally title 'ייצוא הספר' (consistent with the tooltip 'ייצוא הספר' in text_book_screen.dart:1633); keep this a pure layout change, no behavior change. Remember the `hasDivineNames` branch and the English catalog (settings_en.arb / settings_catalogs.g.dart) if strings change.

## Test idea
Extend `test/text_book/view/text_book_export_dialog_test.dart`: the format hint's dy is greater than the holy-names label's dy (fails on dev).

## Pitfalls
