## Requested behavior / DEFAULT
DEFAULT: the confirmation dialog of "קבע מצב זה כברירת מחדל" gets a checkbox "כולל האפשרויות הנוכחיות" (default CHECKED). When checked, confirming saves, for the current lexical mode, the currently active word options (prefix/suffix/… checkboxes), distance, word order and (advanced) proximity policy, through the existing SearchDefaults savers; the snack names what was saved. Smart (semantic) mode: no checkbox (no lexical options). The existing granular submenu stays.
Acceptance:
- Regular mode, options {prefixes, suffixes} on, distance 5 → confirm (checkbox on) → new search window opens in regular mode with those options and distance 5 (fails on dev: only mode saved).
- Checkbox off → only mode saved (old behavior).
- Cancel → nothing saved.
- Any other "default mode" entry point found that skips confirmation: make it consistent (confirmation or documented) and say so in BODY.
