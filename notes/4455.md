# Issue #4455 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: palmoni5 07.11: "לא בטוח שכדאי" (not sure it's worthwhile). NEEDS_DECISION; default below.

## Requested behavior
Opening a bookmark lands at the position but the user must hunt for the exact line; mark it like an Otzaria link "with highlight".
Question: add a highlight on bookmark open, and which kind — the permanent yellow link mark (stays until Esc) or the temporary line highlight already used when opening a personal note?
DEFAULT: the temporary highlight (`HighlightLine(lineIndex)`, same as opening a personal note) — not the yellow permanent mark; it disappears on the next selection/scroll interaction like other temporary highlights. No setting.
Acceptance (default):
- Opening a bookmark (single, from the bookmarks panel/dialog) in a TEXT book highlights the bookmarked line (`highlightedLine`) after the scroll lands; also when the book was already open and is reused (`navigateToPositionIfReused`).
- Opening a bookmark GROUP: only the primary (first) book gets the highlight.
- PDF bookmarks: unchanged (page-level).
- Visual colour = existing `AppSurfaces.highlightedLineBackground` (reader_line_spec.dart L65-67) — no new token.

## Implementation sketch
- Add `highlightLineOnOpen` to the TextBookTab (or to OpenOrFocusTab event) set by tabFromBookmark callers in bookmark_screen; TextBookBloc applies HighlightLine once when Loaded at that index (and on reuse navigation).
- Do not persist the flag in saved tabs (session JSON).
