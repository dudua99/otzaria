# Issue #4663 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Maintainer stance: palmoni5 09.11 "לא בטוח, צריך לחשוב"; dudua99 18.11: folder removal exists in settings.
## Requested behavior
Remove a personal folder from the library directly from the library tree (right-click / actions menu), for ALL personal folders — including folders that were merged into the library tree, not only those under "ספרים אישיים".
## Where in the code
- Already exists for folders under "ספרים אישיים": CategoryActionsMenuButton (lib/library/view/grid_items.dart ~L805-905, commit 32c1db9bd, #1998) offers "מחק מהספרייה"; settings: lib/settings/panels/custom_folders_panel.dart:210 (same removal path). Files on disk are kept.
- Gap: categories that come from a personal folder merged into the main tree get no such menu item.
## Implementation sketch
Detect that a category node originates from a configured personal folder (custom folders list / merged mapping) and offer the same "הסר מהספרייה" action, calling the SAME removal used by settings (no new deletion logic; never delete files on disk). Confirm via the existing confirmation dialog pattern. Official library categories never get the item.
## Tests
Widget test: merged personal folder category shows the menu item; official category does not; selecting it calls the existing removal with the right folder (fails on dev).

Menu item only; before/after capture of the menu with real fonts.
