# Issue #5714 — bug notes (verify everything)
Type: BUG (milestone 0.9.99, from-app, Windows 0.9.98.3). Assignee: none. Maintainer stance: none (no comments). No open PR. SCOPE: only "כשהכנסתי את קובץ הוורד לאוצריא כל הקישורים נעלמו" (the user pasted Otzaria direct links into Word — Word showed its security prompt, i.e. the links are `otzaria://open/book/…` — then added the .docx to Otzaria and all links became plain text).
Constraint: keep the link allowlist safe (no `javascript:`, `data:`, `file:`, other `otzaria://` actions).

## Requested behavior
A Word document (.docx/.docm/.dotx, Flat OPC, WordML 2003; and .odt for consistency) opened/imported as a personal book keeps Otzaria book links (`otzaria://open/book/<id>[?…]`, `otzaria://open/pdf/<id>`, `book://…`) as clickable `<a href>`; clicking opens the book at the location, like in HTML personal books.
Acceptance:
- docx with `<w:hyperlink r:id="rId1">` → rels target `otzaria://open/book/12?index=2` (TargetMode External) → output contains `<a href="otzaria://open/book/12?index=2">` (fails on dev: plain text).
- Same for WordML 2003 `w:hlink w:dest="otzaria://open/book/…"` and ODT `text:a xlink:href`.
- `javascript:` / `otzaria://open/settings` / `otzaria://inline-link…` from a document are still dropped (existing test 'יעד חסר או סכימה חסומה נשארים טקסט רגיל').
- Round trip: Otzaria's own Word export (lib/printing/word_export_service.dart writes `otzaria://open/book/…` hyperlinks, test/printing/word_export_source_links_test.dart L100-110) → re-import keeps the links.
- Already-converted files refresh: converter version bumped so the docx cache is invalidated.

## Root cause / history
Docx link support (4b8f0fe5f, ypl 13.09 "תיקון קישורי Word לאחר rebase", v15) and ODT links (cc646341c, mmichaelush 17.08) call `safeLinkTarget` with the default `allowBookLinks: false`; the HTML converter opted in (4f1d095e8). So Otzaria's own links never survive Word/ODT import. Not a regression; name these commits in BODY.

- Bump `kOoxmlWordConverterVersion` 16→17 (+ "v17:" comment line) and `kOdtConverterVersion` 7→8; update test/utils/file/converter_versions_test.dart (versions + fingerprints only if the sample output changes).
