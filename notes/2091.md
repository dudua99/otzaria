## Requested behavior
Otzar HaChochma catalog books that differ only by volume (~67k rows, e.g. eight "ערוך השלחן") must show their volume.
Acceptance:
- Otzar books with a non-empty `volume` (different from title) display as "<title> – <volume>" (same separator as `_otzarBookLabel`, book_source_dialog.dart L440-447) in the library list, grid, OtzarBookDialog and title search results.
- Title search matches the volume text too (e.g. "ערוך השלחן אורח חיים" finds that volume).
- Opening/linking still uses `book_id` (`externalLibraryId: 'oh:<id>'`); plugin identity (`PluginBookIdentity.keyOf` → `bookId: book.title`, plugin_book_identity.dart L72) keeps the ORIGINAL title (no plugin contract change), unless you add a separate `volume` field to the plugin JSON (optional, additive).
- Old catalog without a `volume` column → unchanged (no crash).
