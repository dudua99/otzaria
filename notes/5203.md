# Issue #5203 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: palmoni5 16.11: "צריך לבדוק מה יש ומה אין ואיך להוסיף את המידע" (check what data exists and how to add it).

## Requested behavior
In the biographies tool, a person's works (חיבוריו) should be links to the book in Otzaria when that book exists in the library.
Data check (answering palmoni5): no explicit work→book mapping exists. Available: `author_biographies.json` (AuthorBiographyLinks: exact catalog AUTHOR name → biography id; asset + download from otzaria-library repo) and each library book's author field. So a runtime match is possible without new data: books whose author maps to this biography id AND whose title matches the work title.
Acceptance:
- In the expanded card's "חיבוריו" row, a work whose title matches exactly one library book (normalized title equality, or work title == book title minus a trailing " על התורה"/"על ..." qualifier — keep conservative) by an author mapped to this biography is rendered as a link (catalog link style, Semantics(link), Enter/Space, tooltip "פתח את הספר"); click opens the book (open_book.dart).
- Ambiguous (several books, e.g. multi-volume) → link opens the library at that book's category/first match? DEFAULT: if all candidates share one parent category, open the first volume; else no link.
- No match → plain text (as today).
- Works without network (uses the bundled crosswalk).

- Card: wrap matched work title in the catalog link widget (check lib/widgets/text or misc for an existing inline link component; no raw GestureDetector without Semantics).
