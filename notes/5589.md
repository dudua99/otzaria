# Issue #5589 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: palmoni5 (maintainer — confirm he has no branch before starting). Maintainer stance: none written. NEEDS_DECISION on UX; default below.

## Requested behavior
Report (r5589): reading "קובץ מאמרים ואגרות חלק ג" with 1 commentary ("הערות") in split view. The commentary pane search ("חפש בתוך המפרשים המוצגים...") only searches what is currently displayed (commentaries linked to the visible base lines). Requests:
1. Search the whole commentary (all its notes in the book), not only the displayed part.
2. In-book search of the base text should optionally include the notes.
Open question: is (1) a new scope in the commentary pane, and is (2) wanted at all? DEFAULT (if owner says proceed): implement (1) only; (2) is served by global search with the book filter.
Acceptance for the default:
- The commentary-pane search field gets a scope toggle: "מוצגים" (current behaviour, default) / "כל הספר".
- "כל הספר": runs the indexed search engine restricted to the commentary books currently selected in the pane (exact mode, same options as in-book search), shows a result count and prev/next navigation (reuse `SearchResultNavigator`).
- Navigating to a result scrolls the BASE text to the line the note is linked to and highlights the match in the commentary pane (same as current navigation).
- If the index is missing/being built, fall back to a clear message (UiSnack catalog) — no silent empty result.
