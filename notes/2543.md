## Requested behavior (item 1 only)
Search scope option "הספרים הפתוחים": restrict the library search to all books currently open in tabs.
Acceptance:
- Scope menu (library search) gets an item "ספרים פתוחים" (icon from otzaria_icons/Fluent) near "כל הספרים"/"ספרי יסוד"; toggling it sets the selection to the facets of all open searchable books.
- Books collected from TabsBloc of the CURRENT window: every leaf pane (`leafPanes(tab)`) incl. split panes; TextBookTab and PdfBookTab only if searchable/indexed (respect `excludeUserBooks` / PDF indexing setting); deduplicated by indexed identity.
- No open searchable books → item disabled with tooltip "אין ספרים פתוחים"; an empty resulting selection must NEVER fall back to "whole library".
- The selection is a snapshot at toggle time (opening a new tab later doesn't change it) — state it in the tooltip/subtitle; it can be saved as a saved scope like any selection.
