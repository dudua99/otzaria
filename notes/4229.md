# Issue #4229 — feature notes (verify everything)
Type: FEATURE/UX (milestone 0.9.99). Assignee: none. Maintainer stance: none. NEEDS_DECISION (navigation model change).

## Requested behavior
Opening the Library while reading replaces the whole screen (unlike Search and Find-ref, which float above the open book); returning requires clicking "עיון". Reporter suggests either a floating library like search/find-ref, or showing the open tabs/a "back to book" affordance while in the library (and not allowing duplicate library windows).
Question: (a) keep full-screen library; (b) floating/overlay library panel over the reader (like find-ref); (c) keep full-screen but add an always-visible "חזרה לספר <title>" button / tab strip in the library screen.
DEFAULT: (c) — least disruptive: in the library screen, when there are open reading tabs, show a compact "חזרה לעיון: <current tab title>" action (ActionButton.inline in the library top bar) and Esc returns to the reading screen; no new window types.
Acceptance (c):
- Library opened from reading with ≥1 open tab → action visible; activating it (or Esc when no text field focused) returns to reading at the same tab.
- No open tabs → action hidden.
- Keyboard shortcut for reading screen (Ctrl+R) unchanged.

## Where in the code
- Screen switching: NavigationBloc `NavigateToScreen(Screen.reading)`; nav items lib/navigation/view/main_window_screen.dart ~L470-500.
- Library top bar: lib/library/view/library_browser.dart (header/search row).
