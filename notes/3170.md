# Issue #3170 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: arieldaniely 27.10: do not limit to a minimum word count, maybe a notice; Y-PLONI 03.11 + palmoni5 16.11: "עזרה נגישה לצד השדה, עם דוגמה לניסוח שאלה והסבר על ציון הקשר ונסיבות ... אין הצדקה לחסימה קשיחה של 15 מילים ... המלצה לא חוסמת".

## Requested behavior
Users get much better smart-search (semantic) results with long, natural-language questions; the app should teach this.
Acceptance:
- Next to the semantic query field there is an accessible help affordance (info icon button with tooltip, opening a short help popover/sheet) explaining: describe the topic in your own words, include context/circumstances, longer questions (≈15–30 words) work better, with one concrete example question.
- Short queries remain allowed — no blocking, no minimum.
- Optional non-blocking hint: when a submitted semantic query has fewer than N words (N≈4), show a subtle inline hint under the field ("טיפ: שאלה מפורטת במילים שלכם מניבה תוצאות טובות יותר"), dismissible, not repeated after the user dismisses it (persist a flag).
- Existing hint text "תארו במילים שלכם את העניין שאתם מחפשים" stays.

## Where in the code
- lib/semantic_search/view/semantic_mode_panel.dart ~L285-317: the query field + hint.
- Submit path: lib/search/view/search_dialog.dart ~L1151-1176 (empty-query check only).
- Catalog: `AppIconButton`/`SquareIconButton` with tooltip (icon from otzaria_icons/Fluent, e.g. `FluentIcons.info_24_regular`), `AppInfoBanner` for the inline hint, popover via existing catalog popover/`AppMenu` (DESIGN_SYSTEM §3) — no raw Dialog.

## Implementation sketch
- Add help button inside/next to the field suffix; content strings via `context.settingsText` + lib/settings/l10n/settings_en.arb (UI text) — check which string catalog semantic_search uses today and follow it.
- Short-query hint: compute word count on submit; show AppInfoBanner (tone info) with close; persist "dismissed" via Settings key (SettingsRepository constant), default false.
