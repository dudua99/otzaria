Type: FEATURE (milestone 0.9.99; labelled bug). Assignee: none. Maintainer stance: Y-PLONI 03.11: "להרחיב את מנגנון הכותרות לחלוקה החודשית, להציג שם יום וטווח/סיום, וליישר גם את הניווט והסימון לכותרת הפרק הפותח. את הסיום לחשב מפסוקים, משום שכותרת הפרק הבא עלולה להשתייך ליום הקודם. לחלוקה שבועית נדרשים נתוני מקור נוספים" + tests for 4th and 11th of month, the 25–26 split inside ch.119, and day 30. palmoni5 16.11 confirms still missing (incl. ranges starting/ending mid-unit).

## Requested behavior
Reading תהילים, the user can't see where "today's" monthly portion ends (e.g. day ד covers כ"ג–כ"ח; day 25/26 split inside psalm 119).
Acceptance:
- In the reader body of Tehillim (any book that has the `30 Day Cycle` alt-TOC structure), an in-text section heading marks the START of each day's portion: "יום ד' לחודש" (Hebrew day), placed at the exact first verse of the portion (alt_toc_entry line), even mid-psalm (119).
- Optionally a subtle end marker "סוף יום ד'" before the next day's first verse — DEFAULT: start headings only (the start of day N+1 implies the end of day N); end marker only if trivial.
- Navigation from the alt-TOC sidebar (`30 Day Cycle` item) scrolls to that start line (already) and the heading is visible there.
- Weekly cycle: not in DB → out of scope (needs source data).
- Toggle: show these day headings only when the user is browsing by that structure? DEFAULT: always show for books that have the structure (like Topic/Parasha headings).

## Where in the code
- lib/data/data_providers/database_library_provider.dart ~L1206-1265: in-text section headings query — `WHERE s.key = 'Topic' OR (s.key = 'Parasha' AND e.level = 0)`; labels via `parashaHeadingLabel`; `buildSectionHeadings(rows, …)` with visibility check of nearby lines.
- Alt TOC sidebar: lib/text_book/view/alt_toc_sidebar_view.dart ~L790-867 (selecting an item navigates to its first link).
- Find the exact structure key in the DB (Y-PLONI calls it `30 Day Cycle`; verify on a v36+ DB: `SELECT DISTINCT key FROM alt_toc_structure`).
