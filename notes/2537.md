## Requested behavior
In the navigation panel's "כותרות" tab (alt structures: דיבור המתחיל, נושאים, סימנים…), the first structure opens expanded, hiding the other structures below a long list; users don't realise more exist.
Question: Option A (all structures collapsed initially, no new button) or Option B (add "כווץ הכל" like in "ניווט")?
DEFAULT (Y-PLONI's audit recommendation, no new button): Option A.
Acceptance (A):
- When a book has ≥2 alt structures, the "כותרות" tab opens with all structures collapsed (headers visible).
- Location sync still MARKS the current heading but does not auto-expand a structure the user hasn't opened in this session; once the user expands a structure, sync may expand its ancestors inside it.
- A manual collapse is never undone by scroll sync.
- Books with a single structure: unchanged (expanded).
