# Issue #4231 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: none.

## Requested behavior
In library search results (and in a book's row/details), the category path and the author name should be clickable: category (or a sub-category segment) → navigate the library to that category; author → show all books of that author.
Acceptance:
- Search-result rows (`_LibraryListItemStyle.search`): the path line (`book.categoryPath`, e.g. "הלכה / טור") renders each segment as a link; activating segment k navigates the library to that category (`NavigateToCategory`) and clears the search (same behaviour as PR #5624 "פתיחת מדף מתוצאות החיפוש מנקה את החיפוש" — build on it, don't duplicate).
- The author subtitle is a link: activates an author filter → library search shows all books whose author equals this author (exact normalized author match; not fuzzy). DEFAULT mechanism: put the author into the library search field with an explicit author prefix if one exists; if the library search has no author-only mode, add an author filter chip "מחבר: X" above results (clearable) instead of inventing query syntax.
- Keyboard/a11y: links are focusable, Enter/Space, Semantics(link), tooltip ("עבור לקטגוריה" / "כל ספרי המחבר"); row tap still opens the book (links consume their own tap).
- Also in the book details/"אודות הספר" author line? Out of scope (author there already opens the biography — commit 1b2383a3e); keep consistent: do not change it.

## Where in the code
- lib/library/view/library_browser.dart ~L2672-2690: `pathLine` (search style only) + `subtitle: book.author` → `_buildLibraryListRowBase` (find it; renders title/subtitle/pathLine); grid variant ~L2769 subtitle author.
- Navigation: lib/library/bloc/library_bloc.dart `NavigateToCategory` (L99, `_onNavigateToCategory` L665); resolving a path string to a Category (category lookup by path — reuse library model helpers).
- Library search matching includes author: lib/data/repository/data_repository.dart ~L519 (`normalizedAuthor`) — check how a query matches authors to implement the author filter precisely.

## Implementation sketch
- Extend `_buildLibraryListRowBase` with optional `onPathSegmentTap(int depth)` and `onAuthorTap` callbacks; render via a small inline-link widget built from catalog text + tokens (no raw colours; link colour from ColorScheme.primary).
- Author filter: new LibraryBloc event `FilterByAuthor(author)` + state field; results = books with equal normalized author; UI chip with clear (catalog chip, DD-13).
