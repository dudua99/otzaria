# Issue #2306 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99; forum). Assignee: none. Maintainer stance: Y-PLONI 03.11: missing capability; "להוסיף התאמות לגודל מפרשים ולמרווח שורות בהגדרות ספר המקור, לחבר את פקדי הקורא לשמירה ולתצוגה שלהן, ולהשתמש בהגדרות הכלליות כברירת מחדל כשאין התאמה. יש להחיל זאת גם בצורת הדף ולעדכן את תיאור המתג" + verification: two open books, change one only, reopen, reset, toggle off.

## Requested behavior
With "שמירת התאמות לכל ספר בנפרד" on, changing the COMMENTARY font size or LINE SPACING in a book still changes the global value for all books. They should be saved per (source) book.
Acceptance:
- When per-book saving is ON: reader controls for commentary font size and line spacing write to that book's `TextBookPerBookSettings` (new fields `commentatorsFontSize`, `lineHeight`), not to the global SettingsBloc values.
- Rendering of that book (commentary pane, split view, page shape commentary columns, main text line spacing) uses per-book value ?? global.
- When OFF: behaviour unchanged (global).
- "Reset per-book adjustments" (text_settings_tab.dart ~L561) clears the new fields too.
- Two books open side by side keep independent values; reopening restores.
- Toggle description updated to mention commentary size and line spacing.

## Implementation sketch
- Add the 2 nullable fields (JSON additive, no migration).
- TextBookBloc state gets effective values; controls dispatch a TextBook event when per-book is on, else the global settings event (one branching helper reused by all controls).
- Consumers read from the book state's effective value.
