# Issue #2838 — feature notes (verify everything)
Type: FEATURE/startup UX (milestone 0.9.99; label performance). Assignee: none. Maintainer stance: Y-PLONI 03.11: reveal waits for the active book in some cases but not for the library catalog; "כשמסך הפתיחה הוא הספרייה, להשתמש בשכבת פתיחה חזותית אחת עד שהקטלוג זמין, עם יציאה לשגיאה או אחרי זמן מוגבל. להשאיר את עצם הצגת החלון ואת עבודות הרקע בסדר הקיים; המתנה גורפת לספרייה תעכב גם משתמש שחוזר לספר שכבר ניתן לקרוא" + verify slow library, load failure, return to saved book, single transition without unbounded wait.

## Requested behavior
On startup the app window appears and then the library shows its own loading indicator a moment later — two loading phases. Make it one smooth phase.
Acceptance:
- ONLY when the startup screen is the library (not reading): the window reveal (`_revealMainWindowOnce`) waits for the library catalog to finish loading (`LibraryBloc` state `isLoading == false` or error), bounded by the existing splash fail-safe timeout (reuse `_splashFailsafeTimer`; do not add a new longer wait).
- Startup into a saved book: unchanged (still waits only for the active book, main_window_screen.dart ~L880-918).
- Library load error → reveal immediately showing the existing error state.
- No new `await` before the first frame (AGENTS Startup Path rules); instrumentation via `StartupTimeline.instance.mark('waitingForLibrary')`/`'libraryLoaded'`.

## Where in the code
- lib/navigation/view/main_window_screen.dart ~L855-918 (`_scheduleSplashReveal`-like method: `_hasScheduledSplashReveal`, `reveal:tabsPending`, `shouldWaitForBook` stream subscription pattern) and `_revealMainWindowOnce` ~L921 (fail-safe timer).
- Library loading indicator: lib/library/view/library_browser.dart ~L618-623 (`isLoading`); LibraryBloc state.
- AGENTS.md "Startup Path (MANDATORY)" section: reveal gate with timeout, non-fatal failure.

## Implementation sketch
- Add `shouldWaitForLibrary = navigationState.currentScreen == Screen.library && context.read<LibraryBloc>().state.isLoading` (verify field name); subscribe like the book case; `finish()` on loaded/error; fail-safe timer already guarantees reveal.
- Keep the single `_revealMainWindowOnce` idempotent path.
