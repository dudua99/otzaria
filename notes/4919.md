# Issue #4919 — feature notes (verify everything)
Type: FEATURE (milestone 0.9.99). Assignee: none. Maintainer stance: palmoni5 11.11: "לחיצה על Esc מבטל את זה", then reopened specifically for: "אולי כדאי להוסיף בפעם הראשונה בתוכנה שיש כזה קישור צהוב, פירוש שיש לחיצה שמבטלת. כמו כל הידעת שיש בתוכנה".

## Requested behavior
The yellow highlight left by an Otzaria link "with highlight" (?mark / pinpoint) stays until Esc; users don't know Esc clears it. Scope (per palmoni5's reopen): a one-time "הידעת?" live tip the first time such a highlight is shown.
Acceptance:
- The first time a text book opens with a link highlight (yellow background on a main-text line), show a live tip: title "הידעת?", body like "הסימון הצהוב מגיע מהקישור שפתחת. לחיצה על Esc מסירה אותו."
- Shown once: dismissing it, or the user pressing Esc to clear a link highlight, marks it resolved forever (LiveTipStorage).
- Desktop only (Esc); on Android/iOS do not show (audience desktopOnly) unless there is a touch way to clear — verify; if none, out of scope.
- No change to the highlight itself (no auto-fade — reporter's original idea was not adopted).

## Where in the code
- Live tips: lib/tour/models/live_tip.dart (`LiveTipId` enum, `TourInteractionType`, `liveTipSpecs` list with `LiveTipAudience.desktopOnly`), lib/tour/bloc/tour_cubit.dart interaction switch (~L280-335) + scheduling/eligibility (~L121, ~L437 launch-count threshold), docs/guided_tour_developer_guide.md (how to add a tip; strings to settings_en.arb + `dart run tool/generate_settings_l10n.dart`).

- Esc clearing: lib/text_book/view/text_book_screen.dart ~L2954-2963 (`ApplyMarkHighlight()` when `permanentHighlightLine != null`); combined_book_screen.dart ~L2313.
- Reporting interactions: see text_book_screen.dart:847 (`TourInteractionType.commentaryAvailable`) for how a screen notifies TourCubit.
