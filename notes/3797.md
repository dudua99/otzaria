## Requested behavior
With many tabs, hovering a tab shows its X immediately, and clicking to switch tabs often closes the tab instead.
Question: adopt a density threshold under which X is shown only on the ACTIVE tab (inactive tabs closable via middle-click/context menu/Ctrl+W)?
DEFAULT: yes — when a tab's width < threshold (e.g. width at which the X would exceed ~⅓ of the label area, or < 90 logical px), inactive tabs show no X on hover; the active tab keeps its X; middle-click and context menu "סגור" still work. Above the threshold: unchanged.
Acceptance:
- 20 tabs at a typical width: clicking the centre-right of an inactive tab switches, never closes.
- Active tab can still be closed with its X; middle-click closes any tab.
- Split/vertical tab strip: same rule.
