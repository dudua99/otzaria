## Requested behavior

Request: a "report a library problem" entry in the library tab, going to the otzaria-library side.
Question: add a library-level report entry? Where is it routed — the existing app-report pipeline (otzaria.org/api/app-reports, server routes to the library repo by type/label) or the book error-report pipeline?

- Add a 5th app-report type "ספרייה" (AppReportType.library) and an entry "דיווח על בעיה בספרייה" in the library browser's overflow/⋮ menu (and in the book ⋮ menu for "בעיה כללית בספר זה", prefilling the book title/identity).
- The report is sent through the existing app-report pipeline with label `library` (and the book identity when opened from a book); the SERVER maps label → otzaria-library repo. That routing is OUT_OF_REPO (otzaria.org app-reports service) — ship the client side behind the label and coordinate.
Acceptance (default):
- Library ⋮ → dialog opens with type "ספרייה" preselected; from a book's ⋮ the book title is included.
- Payload includes `type: library` (+ book identity); existing types unchanged; offline queue works.
